# @magicsandbox.ai/react-sandbox

`@magicsandbox.ai/react-sandbox` is a React Sandbox component for [Magic Sandbox](https://magicsandbox.ai).

## Getting Started

`npm install "@magicsandbox.ai/react-sandbox"`

See [magicsandbox.Assistant](https://github.com/magicsandbox-ai/magicsandbox/tree/main/apps/Assistant) for example usage.
