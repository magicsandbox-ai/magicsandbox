# @magicsandbox.ai/streaming

`@magicsandbox.ai/streaming` is a collection of streaming utilities for [Magic Sandbox](https://magicsandbox.ai).

## Getting Started

`npm install "@magicsandbox.ai/streaming"`

See the [Magic Sandbox docs](https://magicsandbox.ai/?_app=magicsandbox.Docs#streaming-json) for example usage.
